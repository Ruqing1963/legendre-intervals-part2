## 一处需要纠正的提法

您的提示把"非 4-轮换 ⟹ W = 0"归因于"二次型 Q 在根基上严格非零"。这在 **β-形式**（W 作为 F_{q¹²} 上单个二次型的指数和，根基维数 2k+4）中是对的，论文定理的末句也是这样陈述的。但在 **x-形式** W = Σ_{λ₁∈F_q} S(λ₁) 中情况恰好相反：型 (2,3)、(1,1,1,2) 时 **全部 q 个 S(λ₁) 都非零**（|S| = 4q⁶），W = 0 来自符号两两抵消——一半 +4q⁶、一半 −4q⁶。原因是这两种型里 Tr_{q¹²/q} 在 ker L 上恒为 0，而 Q₀ 在 ker L 上也恒为 0（每个根落在 F_{q¹²} 的偶指数子域 F_q、F_{q²}、F_{q³} 里）。L-多项式数据（k = 3,5,7,9）精确给出每类 64/64（k=7）、256/256（k=9）的正负分布。两种说法在数学上等价（|W| ∈ {0, 4q⁷} 迫使 W = 0 ⟺ Q|_R ≠ 0），论文两种都写了。

## 1. 证明的骨架

固定 k 奇，取代表 (λ₃,λ₅) = (t,1)，A(u) = u⁵ + t²u + 1，根 u₀,…,u₄，K = ker L = ker T（维 4），τ = Tr_{q¹²/q}，S(b) = Σ_{x∈F_{q¹²}} ψ(x⁵+tx³+bx)，W = Σ_{b∈F_q} S(b)。

**Lemma 6.9（平移恒等式）。** V := T⁻¹(F_q)。
(a) c ∈ V ⟹ S(b) = (−1)^{Q_b(c)} S(b + T(c))。
(b) c ∈ V ⟺ (σ−1)c ∈ K；此时 τ(c) = (1+σ²+⋯+σ¹⁰)(σ−1)c。
(c) c ∈ V 且 τ(c) = 0 ⟹ W = (−1)^{Q₀(c)} W。于是只要找到一个 c 使 Q₀(c) = 1，W = 0。

**Lemma 6.10（二次因子 ⟹ W = 0）。** 设 A 有 F_q 上不可约二次因子 u²+κu+N。做除法得 N = κ⁻³，t² = κ⁴ + κ⁻¹ + κ⁻⁶，不可约 ⟺ Tr(N/κ²) = Tr(κ⁻⁵) = 1。取该因子的根 u ∈ F_{q²}，c ∈ F_{q⁴} 满足 c^q + c = u（Tr_{q⁴/q} u = 0 保证存在）。则 (σ−1)c = u ∈ K ⟹ c ∈ V；τ(c) = 6u = 0；c 的四个共轭是 c, c+u, c+κ, c+u'，于是
Q₀(c) = Tr_{q/2}(Σ(c_i⁵ + t c_i³)) = Tr(Σa_i⁵ + tΣa_i³) = Tr(1 + κ⁻⁵ + tκ⁻²)，
而 tκ⁻² = 1 + κ^{−5/2} + κ⁻⁵，所以 Q₀(c) = Tr(κ^{−5/2}) = Tr(κ⁻⁵) = 1。∎ 这覆盖型 (2,3) 和 (1,1,1,2)。

**Lemma 6.11（4-轮换：F_q、F_{q²} 上的小和决定符号）。** u₀ ∈ F_q，σ: u₁→u₂→u₃→u₄→u₁。令 κ = 1 + Tr(u₀⁵ + tu₀³)，s_m(b) = F_{q^m} 上的和。
(a) S(b) ≠ 0 ⟺ Tr(bu₀) = κ ⟺ s₁(b) = 0。
 证明：x-判据是 Tr(bx) = Q₀(x) 对 x ∈ K；在 u₀ 上两边为 0；在 u_i（i ≥ 1）上 Tr(bu_i) = Tr_{q/2}(b·Tr_{q⁴/q}u_i) = Tr(bu₀)，Q₀(u_i) = Tr(p₅ − u₀⁵ + t(p₃ − u₀³)) = Tr(1 + u₀⁵ + tu₀³) = κ（A 的 Newton 恒等式：p₃ = 0，p₅ = 5e₅ = 1）。另一方面 F_q 上二次型的根基是 K^σ = {0,u₀}，s₁ ≠ 0 ⟺ Tr(u₀⁵+tu₀³+bu₀) = 0。
(b) s₁(b) = 0 ⟹ s₂(b) = 0。
 证明：F_{q²} 上根基 K^{σ²} = span(u₀, w)，w = u₁+u₃，w' = u₂+u₄，w+w' = u₀，N₂ = ww'。**关键恒等式 N₂ = u₀^{1/3}**：B = A/(u+u₀) = u⁴+u₀u³+u₀²u²+u₀³u+u₀⁻¹ 的预解三次式是 (θ+u₀²)³ + u₀，唯一 F_q-根 M = u₁u₃+u₂u₄ = u₀² + ρ（ρ³ = u₀），N₂ = e₂(B) + M = ρ。于是 Tr_{q²/2}(w⁵+tw³+bw) = 1 + Tr(ρ¹⁰+ρ⁵+tρ⁴) = 1 + Tr(tρ⁴)，而 t = ρ⁶ + ρ^{−3/2} 给出 tρ⁴ = ρ¹⁰ + ρ^{5/2}，迹为 0。故二次型在 w 上取 1，s₂ = 0。
(c) e₁ = −s₁ = 0，e₂ = (s₁² + s₂)/2 = 0，函数方程给 L_C(T) = 1 + q²T⁴，ω_i⁴ = −q²，S(b) = −Σω_i¹² = +4q⁶。W = (q/2)·4q⁶ = 2q⁷。∎

**Prop 6.8（分解型计数，现在对所有奇 k 证明）。** 两步：
- 只有三种型：F_q 上二次型 Tr(x⁵+tx³) 的根基是 K^σ，其维数 ≡ k ≡ 1 (mod 2)；S₅ 的和零模上各轮换型的固定子空间维数为 (1,4):1, (2,3):1, (1,1,1,2):3, (5):0, (1,1,3):2, (1,2,2):2, (1⁵):4，偶数者排除。
- 计数：(i) v ↦ v⁵+v 在 F_q 上零点恰 {0,1}，N₁ + 3N₃ = q−2；(ii) v ∈ F_{q²}∖F_q 且 v⁵+v ∈ F_q ⟺ s⁴+ns²+n² = 1（s = v+v̄，n = vv̄），化为 m²+m = 1+s⁻⁴ 且 Tr m = 1，恰有 q 个这样的 v，故 2N₀ + 2N₃ = q；(iii) N₁+N₀+N₃ = q−1。解得 N₁ = (q−2)/2，N₃ = (q−2)/6，N₀ = (q+1)/3。

**Theorem 6.12 + Corollary 6.13。** 组合以上即得；Σ_mixed W = (q−1)·(q−2)/2·2q⁷ = (q−1)(q−2)q⁷ 正是 eq:mixedsum，故 A₆ = q⁹ + (q−1)q⁵（k 奇）。

## 2. 数值验证（与二次型算法独立）

`kasami_sign.py`：对每个 j ∈ F_q^× 和每个 b ∈ F_q，用 F_q、F_{q²} 上的两个小和 s₁、s₂ 确定亏格 2 超奇异曲线 y²+y = x⁵+tx³+bx 的 L-多项式 1 + s₁T + ((s₁²+s₂)/2)T² + qs₁T³ + q²T⁴，进而 S(b) = −Σω_i¹²，再求和得 W。结果（`data/kasami_sign_k357.txt`，`data/kasami_sign_k9.txt`）：

**调试记录（诚实说明）。** 第一版脚本把 x⁻¹ 写成 `gf.pow(x, order−2)`（正确的是 `order−1`，因为 order = 2^N − 1），得到的是 x⁻²；由于平方是 Frobenius，分解型和 κ 没受影响，但 u₀ 被换成了 t^{1/2}v₀² 而非 t^{1/2}v₀，导致"λ₁ 的陪集"判错，一度出现"部分 κ=1 的 S(λ₁*) = 0"的假象。查出后，全部 q 个 b 的谓词 100% 吻合。第一版的 Newton 递推也有一个 p₀ = 4 的系数错误，已改正。
