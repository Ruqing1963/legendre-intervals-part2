**需要指出的一点。** "相长干涉主导求和"不是一个可以对任意 φ 证明的命题——折叠恒等式对任何函数成立，而相干与否取决于 Fourier 系数的符号结构。本文能证明的是：d = 4 的全部纤维和（精确闭式）、d = 6 的纤维和用三个常数 A₆、X、Y 的精确表达，以及放大因子 ≍ q² 来源于 q 个"阶 ≤ 2 纤维"的相干；"为什么这些纤维相干"最终归结为 §6 的 Arf 符号定理（已证的 4-轮换情形）和 Table 3 的符号模式（X 部分仍是猜想）。

## 1. 折叠恒等式（Prop 8.1）

G 有限阿贝尔，H ≤ G，H^⊥ = (G/H)^。φ = Σ c_χ χ。
- Res: Ĝ → Ĥ 满，纤维 = 陪集 χH^⊥，大小 [G:H]。
- f_ψ := Σ_{fibre} c_χ = (1/\|H\|)Σ_{h∈H} φ(h)ψ̄(h)（φ 在陪集 H 本身上的 ψ-系数）；E_ψ := Σ_{fibre}\|c_χ\|² = 陪集平均 \|F_{gH}(ψ)\|²（φ 在各陪集 gH 上 ψ-系数的均方）。
- Var_G = Σ_ψ E_ψ，Var_H = Σ_ψ \|f_ψ\|²；\|f_ψ\|² ≤ [G:H]E_ψ；κ_ψ := \|f_ψ\|²/([G:H]E_ψ) ∈ [0,1]。
- Gram 矩阵 M_{χ₁χ₂} = [χ₁χ̄₂ ∈ H^⊥]：按纤维分块的全 1 块，特征值 [G:H]（纤维上常值向量）与 0；Var_H = c*Mc。

## 2. d = 4（Theorem 8.2，精确）

H = G² = {(0,c,0)} ≅ F_q，ψ_μ(c) = χ(μc)。由 Theorem 3.2：φ(id) = −q⁴+q³，φ(0,c,0) = (−1)^k q³。
f_{ψ₀} = ((−1)^k − 1)(q³ − q²)，f_{ψ_μ} = −q³ + q² − (−1)^k q²（μ ≠ 0）；Σ\|f\|² = q⁷ − q⁶ ✓；Var_G = 3q⁵ − 3q⁴，其中恒等类贡献 q⁵ − 2q⁴ + q³ —— 这就是 Var_G/q⁵ → 3 = 2（KR）+ 1（恒等类）的分解。放大 q²/3。
机制：单个类（恒等类）的亏损 −q⁴ 在 Ĝ² 上的 Fourier 变换是平的（每个 ψ_μ 都 ≈ −q³），每个纤维相干（κ ≈ 1/3，表中 0.225–0.35）；在全群上同一个类被 [G:G²] = q² 稀释。纤维结构：ψ_μ 上方是 χ² = ε_{(√μ,0)} 的 q² 个 4 阶特征；ψ₀ 上方是 q² 个二次特征 ε_λ，系数 S_λ/q³（F_{q⁸} 上的 Artin–Schreier 和）。Theorem 3.12 的 ρ = 1 恰对平凡于 {c₁=0} ⊃ supp φ 的 ε 成立——平移不变的系数向量。

## 3. d = 6（Prop 8.3，精确）

H = G² = {(c₂,c₄)} ≅ W₂(F_q)（Witt 加法 (c₂,c₄)(c₂′,c₄′) = (c₂+c₂′, c₄+c₄′+c₂c₂′)），特征 ψ_{(a,b)}(x) = i^{Tr_{W₂(F_q)/Z4}((a,b)·x)}：a = 0 时阶 ≤ 2（q 个），a ≠ 0 时阶 4（q²−q 个）。
- f_{(0,0)} = (A₆ − q⁹)/q²，f_{(0,b)} = X/q²（b ≠ 0），Σ_{阶 4}\|f\|² = q³(q−1)m_k²（三值定理：±q²m_k 项只落在阶 4 特征上，常数项只落在阶 ≤ 2 特征上）。
- **Var_{G²} = [(A₆−q⁹)² + (q−1)X²]/q⁴ + q³(q−1)m_k²**（所有 k，无条件）。代入 A₆、X 的闭式得相干部分 (q−1)(q+3)q⁷，与 Theorem 7.1 一致。
- 数值（q = 16）：阶 ≤ 2 的 16 个纤维携带 Var_{G²} 的 99.8%，但只占 Var_G 的 14.6%；κ ≈ 0.09；阶 4 的 240 个纤维 κ ≈ 3·10⁻⁵（完全不相干，实际上被折叠"去放大"）。放大因子 51.8 = 0.20 q²。
- 纤维的算术内容：ψ_{(0,0)} 上方是 q³ 个二次特征（系数 S(λ)/q⁵，超奇异 AS 曲线，Theorem 6.1）；ψ_{(0,b)} 上方是 χ² = ε_{(b^{1/4},0,0)} 的 4 阶特征（系数 S′(λ)/q⁵，§6.7 的 Witt 型和）；阶 4 的 ψ 上方是 G₅ 的 8 阶特征（长度 3 的 Witt 向量和，不是二次型和）——这正是 Y 没有闭式的原因。

## 4. 统一图像（Remark）
两个情形都是：偏差集中在 G² 的一个小子群 K 上（d=4：K = {1}，φ ≈ −q⁴；d=6：K = {c₂=0}，\|K\| = q，φ ≈ ε₀q⁵），支撑在 K 上的函数的 Fourier 变换沿 Ĝ² → K̂ 的纤维常值，折叠到 G² 时同相叠加，在 G 上则被 [G:G²] 倍稀释；\|K\|φ_K²/\|G²\| 除以 q^{d+1} 在两种情形都恰为 q²。特征 2 的特殊之处不在折叠恒等式，而在于 (i) 指数 q^{d/2} 的子群 G² 的存在（2-挠），(ii) 使 φ_K 达到 q^d、q^{d−1} 的 Arf 偏置。
