## 1. 为什么这个问题比 A₆ 更难

A₆ 的混合项由一个五次式 u⁵+t²u+1 控制：ker L 是它五个根的和零张成，Frobenius 落在 S₅，只有三种型。对 X，核方程是
L′(x) = λ₅⁴x¹⁶ + λ₃⁴x⁸ + **x⁴** + λ₃²x² + λ₅x = 0，
多出来的 x⁴ 来自 e₂ 的极化形式 Tr(y(x + Tr x))。它破坏了五次分解（x⁴L′ = R² + R + x⁴，不再是 R² + R），也破坏了标度对称（(λ₃,λ₅) ↦ (s³λ₃, s⁵λ₅) 不再是对称性，所以 W′ 不是 j 的函数）。数值表明 Frobenius 在 4 维核上的共轭类取遍 S₆ ≅ Sp₄(F₂) 的全部 11 个类（没有 A₈ 的 7 阶、15 阶类），各类个数恰为 S₆ 密度乘 q² 的精确多项式修正，例如
- 5-轮换（根在 F_{q⁵}，K′ = 0，d = 0，W′ = −q⁷）：(q²+1)/5；
- 6-轮换（轨道 (3,6,6)，W′ = 4q⁷）与 3·2·1（轨道 (1,2,3,3,6)，W′ = 0）：各 (q+1)(q−2)/6；
- 两个 4 阶类（轨道都是 (1,2,4,4,4)，d = 2）：(q−2)(q−4)/8 个取 +2q⁷，q(q−2)/8 个取 −2q⁷；
- 单位类 (1¹⁵)：(q−2)(q−8)/720，720 = |S₆|。
这些精确多项式强烈暗示：ker L′ 应是某个 e₁ = 0 的**六次式**六个根的两两和（S₅ 情形是 r₆ = 0 的退化），正如 ker L 是五次式根的张成。找到这个六次式并逐类计算根基上的取值与 Arf 符号，就是证明 Conjecture 6.19 的路径；主导项 −q⁹/5 来自 5-轮换类的符号 −，这是最关键的一步。我没有完成这一步。

## 2. 已证明的部分（摘要）

**Prop 6.14。** W′(λ₃,λ₅) = Σ_{λ₁} S′(λ) = q Σ_{x∈H₀} (−1)^{Q′_λ(x)}，Q′_λ = Tr(λ₅x⁵+λ₃x³) + Tr_{q/2}e₂(x)；极化形式 Tr(y(T_λ(x) + x + Tr x))；H₀ 上的根基 = {x ∈ H₀ : L′(x) ∈ F_q} = (σ−1)⁻¹(ker P|_{K′})，P = 1+σ²+⋯+σ¹⁰ = (σ+1)²(σ²+σ+1)⁴；维数 k + d。d = 0 当且仅当 K′ = ker L′ ∩ F_{q¹²} = 0，此时 Q′ 在根基 F_q 上为零（F_q-平移不变性），W′ = ±q⁷。β-形式根基维数 2k + d，与 `qf_k*.txt` 的 r 列完全吻合。

**Lemma 6.15。** 取 c 满足 c^{q²}+c = 1，则 θc = 1，平移 β ↦ β+c 消去线性项；Coulter 定理给 Σ(−1)^{Tr β^{q+1}} = −q⁷（N = 12k，d = k，N/2d = 6 偶，a = 1 为 2^k+1 次幂）；Tr(c^{q+1}+c) = k mod 2。故 W′(0,0) = (−1)^{k+1}q⁷，与 k = 1..7 数据一致。

**Lemma 6.16。** λ₅ = 0：L′ = x²(λ₃²x³+x+λ₃)²，核 ↔ z³+z = λ₃²。根基上取值：有理根 y = z/λ₃ 处为 Tr(z^{1/2}/(z+1)) = Tr(z/(z+1)²) = 0；二次因子的根处为 1 + Tr(1/s)（s 为有理根），而二次因子不可约 ⟺ Tr(1/s) = 0。于是型 (1,2) ⟹ W′ = 0，型 (1,1,1)、(3) ⟹ \|W′\| = 2q⁷。个数 (q−2)/6 + (q+1)/3 = q/2。

**Lemma 6.17。** λ₃ = 0：x = y₀w（y₀⁵ = λ₅⁻¹）后核方程为 w¹⁵ + y₀⁸w³ + 1 = 0，令 v = w³ 得 v⁵ + y₀⁸v + 1 = 0，再令 v = y₀²v′ 得 v′⁵ + v′ = λ₅²——又是 Gold 五次式！核元素 = 五个根的立方根。型 (1,4) → 轨道 (1,2,4,4,4)，d = 2；型 (2,3) → (3,6,6)，型 (1,1,1,2) → (1,1,1,2⁶)，d = 4。所以 \|W′(0,λ₅)\| ≤ 2q⁷ 恰对 (q−2)/2 个 λ₅，≤ 4q⁷ 对 q/2 个；数据表明取等且为正。
