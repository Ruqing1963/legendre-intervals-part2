## 1. 递推分析（指令 3.1.1）

m_k = 13, −1, −35, 47, 733；Y_k = 8^k m_k = 104, −64, −17920, 192512, 24018944。

- Berlekamp–Massey（Q 上）：L = 3。五个数的线性复杂度一般就是 ⌈5/2⌉ = 3，且 2L > 5 时连接多项式不唯一（阶 3 的递推由 n = 4, 5 两个方程决定三个未知数，是单参数族）。
- 阶 1（由 m₁, m₂）：预测 m₃ = 1/13 ≠ −35。阶 2（由 m₁..m₄）：c = (−24/19, −53/19)，预测 m₅ = 727/19 ≠ 733。特征根 −0.63 ± 1.55i（对 m）即 λ = 8× 之，|λ| = 2^{7.48}：不是 Weil 数。
- 真实的 L_σ 的阶是 Σ_j dim H^j_c(X, L)，对 A¹² 中次数 (1,3,5) 的 9 维完全交带 Artin–Schreier 层，应在数百以上；要用 BM 识别它需要 Y_k 到 k ≈ 2·阶，远超可计算范围（k = 6 已是 F_{2^{72}}）。

## 2. 超奇异型分解的 2-adic 障碍（指令 3.1.2）

若所有 F-特征根形如 2^{w/2}ζ（ζ 单位根；这正是 A₆、X 背后的二次型和的形状），则 Y_k = Σ_w 2^{wk/2}A_w^{(k)}，A_w^{(k)} ∈ Z[ζ_N] 为代数整数。
- 纯权重 w：Y₂ = 2^w A = −64 ⟹ 2^{w−6} | 1 ⟹ w ≤ 6。所以纯权重 7, 8, 9, … 全部不可能（w = 9 时 A = −1/8）。
- 混合权重：v₂(Y_k) = 3k（m_k 奇）；权重 ≥ 7 的部分 2-adic 赋值 ≥ 7k/2 > 3k，故必有权重 ≤ 6 的非零部分——这正好是"q³ 扭"本身的权重（m_k 中的 O(1) 项）。
- 由此，"m_k 是若干亏格 1、2 超奇异曲线 Weil 迹的整系数组合"若成立，必含一个有界（权重 ≤ 6）分量加上更高权重分量；五个值不足以识别它们。一个观察（未解释）：ε₀m_k ≡ 1 (mod 12)，(ε₀m_k − 1)/12 = 1, 0, −3, −4, 61。

## 3. 几何等价形式与路线图（指令 3.1.3）

**Prop 7.9。** (a) 标度 α ↦ sα 保持 U 且 e₄ ↦ s⁴e₄，s ↦ s⁴ 是 F_q^× 的双射，故 N_c = N₁ (c ≠ 0)，Y = N₀ − N₁，A₆ = N₀ + (q−1)N₁。k 奇：N₁ = (A₆ − Y)/q = q⁸ + q⁵ − q⁴ − q²m_k。数值：

(b) φ: G_m × X₁ → X ∖ X₀，(s, z′) ↦ sz′：有限（s⁴ = e₄ 整），满，radicial（特征 2 中 s ↦ s⁴ 单）⟹ 泛同胚；L_ψ(s⁴) ≅ L_ψ(s)；Künneth + 切除给出长正合列。(c) lci 上平移常值层 perverse + Artin 消没 ⟹ H^j_c(X, L) = 0 (j < 9)，H^j(X, L) = 0 (j > 9)。

**Prop 7.10(c)。** Corollary 6.13 的上同调读法：k 奇时 Tr(σF^k | H^•_c(X, Q_ℓ)) = 2^{9k} + 2^{6k} − 2^{5k}；Conjecture 6.5（A₆，全部 k）等价于 Tr = 2^{9k} − (−64)^k + (−32)^k：X 的非扭系数上同调是 Tate 型的，σ 在权重 12、10 的类上作用为 −1。

**路线图（诚实版）。** m_k = O(q^{3/2}) ⟸ 两个 8 维仿射完全交 X₀ = {e₁=e₃=e₄=e₅=0}、X₁ = {e₁=e₃=e₅=0, e₄=1} 在 9 ≤ j ≤ 15 的 H^j_c 权重 ≤ 9，且二者的顶类在正合列中相消。对"无穷远处一般位置"的光滑仿射完全交，期待的是 8-球面花束加顶类的上同调，那会给出更强的 Y = O(q⁴)、m_k = O(q)（数据 |m_k|/q ≤ 23 与秩 ≥ 23 不矛盾）。两个障碍：奇异轨迹（维数 ≤ 4，坐标中不足五个互异值处）；无穷远处 X̄₀、X̄₁ 与超平面的交都是锥 X₀ 的底 P(X₀)，不是横截的。这些是 Milnor 纤维/消失圈层面的局部计算，本轮未做。
