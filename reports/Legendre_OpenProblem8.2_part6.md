## 1. 纯五次项（Lemma 6.3）——完整证明

设 λ₃ = 0，λ₅ ∈ F_q^×。M(y) = λ₅y⁴ + (λ₅y)^{1/4}，ker M = {0} ∪ {y : y¹⁵ = λ₅⁻³}。

**(i) 核的形状.** y¹⁵ = λ₅⁻³ 在 F_{q¹²} 中可解 ⟺ λ₅ 是 F_{q¹²} 中的五次幂（若 y¹⁵ = w³ 则 y⁵ = wω，ω ∈ μ₃ ⊂ 五次幂）。a ∈ F_q^× 是 F_{q¹²} 中五次幂 ⟺ a^{(q¹²−1)/5} = 1 ⟺ (q¹²−1)/(q−1) ≡ 0 (mod 5) 或 a ∈ (F_q^×)⁵ ⟺ 4 ∤ k 或 a ∈ (F_q^×)⁵。可解时取 y₀⁵ = λ₅⁻¹，则 ker M = y₀·F₁₆（μ₁₅ ∪ {0} = F₁₆ ⊂ F_{q¹²}）。

**(ii) Stickelberger.** 因 2² ≡ −1 (mod 5)，F_{2^{4s}} 上 5 阶特征的 Gauss 和是纯的：G(χ) = (−1)^{s−1}2^{2s}（Berndt–Evans–Williams Thm 11.6.3）。取 4s = 12k：
S(0,0,a) = Σ_{x∈F_{q¹²}} ψ₀(ax⁵) = Σ_{j=1}^{4} χ^{−j}(a)G(χ^j) = ε₀q⁶(5·[a 为五次幂] − 1)。
`legendre_d6_qf_mixed.py` 对 k = 1,3,5 的全部 λ₅ 核验此式（"Stickelberger … OK"）。

**(iii) 四种情形.**
- *4 | k，λ₅ ∉ (F_q^×)⁵*：ker M = 0，β-根基 = ker θ = F_{q²}，维数 2k，|W| = q⁷；每个 S(λ₁) 的 x-根基平凡，|S| = q⁶，|W| = q·q⁶ 迫使 q 个符号相同 = S(0,0,λ₅) 的符号 = −ε₀ = +。W = +q⁷。
- *λ₅ 为五次幂，k 偶*：y₀ ∈ F_q（4|k）或 ∈ F_{q²}（k ≡ 2 mod 4，因 5 | q+1）；F₁₆ ⊂ F_{q²}，故 ker M ⊂ F_{q²} ⊂ im θ，dim R = 2k+4。对 y = y₀c（c ∈ F₁₆）取 β_y ∈ F_{q⁴}，Tr_{q⁴/q²}β_y = y^q，得 Q(β_y) = Tr_{q²/2}(λ₅y^{4q+1}) = Tr_{q²/2}(ρ⁴c^{4q+1})，ρ = y₀^{q−1} ∈ μ₅；c^{4q+1} = c⁵（q ≡ 1 mod 15）或 c²（q ≡ 4 mod 15）；而 c ∈ F₁₆ ⊂ F_{q²} 时 Tr_{q²/2}(x) = (k/2)Tr_{16/2}(x)。4 | k：k/2 偶 ⟹ Q|_R = 0 ⟹ |W| = 4q⁷；x-侧全部 q 个 S 非零（Q_x(y₀c) = Tr_{q¹²/2}(c⁵) = 3k·Tr_{16/2}(c⁵) = 0，c⁵ ∈ F₄；线性条件 Tr(λ₁y₀c) = Tr_{q/2}(12λ₁y₀c) = 0），|S| = 4q⁶，|W| = q·4q⁶ 迫使同号 = S(0,0,λ₅) 的符号 = 4ε₀ = −；W = −4q⁷。k ≡ 2 mod 4：k/2 奇 ⟹ Q(β_{y₀c}) = Tr_{16/2}(ρ²c) 非恒零 ⟹ W = 0。
- *k 奇*：x ↦ x⁵ 在 F_q^× 上双射，y₀ ∈ F_q；F₁₆ ⊄ F_{q²}，q² ≡ 4 (mod 15)，Tr_{q¹²/q²}(y₀c) = y₀Σ_{i<6}c^{4ⁱ} = y₀(c + c⁴) = 0 ⟺ c ∈ F₄。故 ker M ∩ im θ = y₀F₄，dim R = 2k+2。Q(β_{y₀c}) = Tr_{q²/2}(λ₅y₀⁵c^{4q+1}) = Tr_{q²/2}(1) = 0（4q+1 ≡ q+1 ≡ 0 mod 3，c³ = 1）。|W| = 2q⁷。x-侧：x-根基 y₀F₁₆（维 4），Q_x = 0；线性条件 Tr_{q¹²/2}(λ₁y₀c) = Tr_{q/2}(λ₁y₀)·Tr_{16/2}(c)（q 在 F₁₆ 上作用为 Frob² 或 Frob³，12 个共轭把 c,c²,c⁴,c⁸ 各跑 3 次），恰 q/2 个 λ₁ 使 |S| = 4q⁶，|W| = (q/2)·4q⁶ 迫使同号 = S(0,0,λ₅) 的符号 = +4ε₀ = +。W = +2q⁷。∎

与数据（Table 2）逐项相符。于是纯项之和为 2(q−1)q⁷（k 奇）、−2(q−1)q⁷（k 偶），Conjecture 6.4（A₆）等价于
Σ_{mixed} W = ε₀(q−1)(q−2)q⁷。

## 2. 混合项（k 奇）的结构定理（Prop 6.6）

**(a) 只依赖 j.** 伸缩 β ↦ sβ 把 (λ₃,λ₅) 变为 (s³λ₃, s⁵λ₅)；k 奇时 3,5 ∤ q−1，s ↦ (s³,s⁵) 单射，轨道大小 q−1，轨道 = j = λ₃⁵/λ₅³ 的纤维。（`legendre_d6_qf_mixed.py` 断言 W 在每个 j-纤维上常值。）

**(b) 核的分解.** 令 y = λ₅^{−1/5}u，t = j^{1/5} ∈ F_q（k 奇时唯一）。核方程化为 P_j(u) = u¹⁵ + t⁴u⁷ + t²u + 1 = 0，且
P_j(u) = (u⁵ + t²u + 1)(u¹⁰ + t²u⁶ + u⁵ + 1)，
验证：u⁵P_j(u) = (u¹⁰+t²u⁶+u⁵)² + (u¹⁰+t²u⁶+u⁵)。再令 u = t^{1/2}v：u⁵ + t²u + 1 = t^{5/2}(v⁵ + v + c)，c := t^{−5/2} = j^{−1/2}。五根 u₀..u₄ 之和为 0（u⁴ 项系数 0），除此无 F₂-关系（三项关系迫使另两根相等——A 可分；四项关系迫使第五根为 0——A(0) = 1），故 ker L = {0} ∪ {u_i} ∪ {u_i + u_{i'}}，第二因子的 10 个根恰是两两之和。Frobenius 通过其在五根上的置换 g ∈ S₅ 作用于 ker L（标准嵌入 S₅ → GL₄(F₂)，零和模）。

**(c) 由 g 的轮换型读出一切.**
- ker L ⊂ F_{q¹²} ⟺ g¹² = 1 ⟺ g 无 5-轮换。
- 零和模 V ≅ F₂[ℤ/4]（g 为 4-轮换时）：Σ_{i<12}gⁱ = (1+g)³ 秩 1，Σ_{i<6}g^{2i} = (1+g)² 核维 2；g 的阶为 1,2,3,6 时两算子在 V 上为 0。故 4-轮换：Tr_{q¹²/q}(ker L) 为 1 维，ker L ∩ im θ 维 2，β-根基维 2k+2，|W| ∈ {0, 2q⁷}；其它型：迹像为 0，ker L ⊂ im θ，β-根基维 2k+4，|W| ∈ {0, 4q⁷}。
- x-侧：|S(λ₁)| ∈ {0, 4q⁶}，S ≠ 0 ⟺ Tr(λ₁·) ≡ Q_x 于 ker L。4-轮换时 Q_x 在四个 4 次根上取同一值 κ = Tr_{q/2}(1/(1+v₀)²)（v₀ 为 F_q-根），在 u₀ 上为 0，即 Q_x = κ·[Tr ≠ 0]，落在 λ₁-泛函的像里，故恰 q/2 个 λ₁ 使 S ≠ 0；其它型：全部或没有 λ₁ 使 S ≠ 0。

数据（k = 1,3,5；k = 7 的根基）：4-轮换类 S 的多重集 = {0 (q/2), +4q⁶ (q/2)}，W = 2q⁷；其它类 = {−4q⁶ (q/2), +4q⁶ (q/2)}，W = 0；x-根基恒为 4。全部与 (c) 吻合。

**(d) 五次式的分解统计（Prop 6.7）.** `quintic_check.py`（k = 3..11）：c ∈ F_q^× 时 v⁵+v+c 的型只有 (1,4)、(1,1,1,2)、(2,3)，个数 (q−2)/2、(q−2)/6、(q+1)/3；从不不可约。F_q-根数 1、3、0 的个数 2^{k−1}−1、(2^{k−1}−1)/3、(2^k+1)/3 与 Helleseth–Kholosha 关于 x^{2^l+1}+x+a（gcd(l,k)=1）的定理一致。并且 **W(j) ≠ 0 ⟺ v⁵+v+j^{−1/2} 型为 (1,4)** 对 k = 3,5,7 的每个 j 逐一成立。

**(e) 求和.** 若 Conj 6.8（4-轮换 ⟹ W = 2q⁷，其它 ⟹ 0）成立，则 Σ_mixed W = (q−1)·(q−2)/2·2q⁷ = (q−1)(q−2)q⁷，正是 §1 末所需；即 k 奇时 Conjecture 6.4(A₆) ⟸ Conj 6.8 + HK 计数。

## 3. 为什么不是迹方程，以及还缺什么

- "W ≠ 0" 是 Frobenius 在 ker L（4 维 F₂-空间）上为**正则幂幺（阶 4）**的条件——一个 ℤ/4-条件，对应 Hayes 群的 Witt 向量 W₂ 结构。F₂-迹条件 Tr(f(j)) = 0 描述的是 ℤ/2-覆盖，不可能刻画它；这与 k = 5,7 对全部单项 Tr(jᵐ) 及两项 Tr(jᵃ)+Tr(jᵇ)、有理型 Tr(jᵃ/(j+1)ᵇ) 的扫描均无命中一致（k = 5 的 Tr((j+1)⁻³) 命中是小域巧合，k = 7 不成立）。
- **缺口 1（符号）**：4-轮换情形下 Q_β 在根基 θ⁻¹(ker L ∩ F_{q²}) 上为 0 且 q/2 个非零 S(λ₁) 同为 +4q⁶。前者可仿 Lemma 6.2 用 β_y ∈ F_{q⁴} 计算 Tr_{q²/2}(λ₃y^{2q+1} + λ₅y^{4q+1})（y ∈ {c₀u₀, c₀(u₁+u₃), c₀(u₂+u₄)}），需要对称函数运算；后者等价于 Kasami 型和 S(0,λ₃,λ₅) = Σ_x(−1)^{Tr(λ₅x⁵+λ₃x³)} 在此情形取 +4q⁶，目前只有 Kasami 的权分布（给出值的分布，不给出哪个 (λ₃,λ₅) 取哪个值）。
- **缺口 2**：非 4-轮换情形 Q_β 在根基上非零（等价于 W = 0 而非 ±4q⁷）。
- **缺口 3**：k 偶时 j 不是完全不变量（s ↦ (s³,s⁵) 非单射），混合项取 {−4q⁷, q⁷, 0}，未做同样的分析；X 的求和（W′）亦未处理。

因此：Lemma 6.3 是新定理；Conjecture 6.4 仍是猜想，但已归结为 Conj 6.8（纯粹关于五次式 v⁵+v+c 的 4-轮换情形的两个 Arf 符号陈述）。论文中 Theorem 7.1 的前提保留。
