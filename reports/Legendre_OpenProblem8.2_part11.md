## 1. Prop 9.1（已证）：平移轨道与 Lucas 阶跃
- α ↦ α + c 保持 U_d = {Tr α^j = 0, j 奇 ≤ d−1}，诱导 G² 上的双射 τ_c，Ψ∘τ_c = Ψ；e_j(α+c) = Σ_i C(2d−i, j−i) e_i(α) c^{j−i}。
- 恒等类的轨道 K_d = {(1+cu)^{2d} mod u^d} = {(C(2d,j)c^j)_{j≤d−1}}。Lucas：C(2d,j) 奇 ⟺ j 的二进制位 ⊆ 2d 的二进制位；最小的 j ≥ 1 是 2d 的最低位 2^{v+1}（2^v ∥ d），它 ≤ d−1 当且仅当 d 不是 2 的幂。故 \|K_d\| = 1（d = 4, 8, 16, …）或 q（d = 6, 10, 12, 14, …）：K₄ = {1}，K₆ = {1+c⁴u⁴} = {c₂ = 0}，K₈ = {1}，K₁₀ = {1+c⁴u⁴}，K₁₂ = {1+c⁸u⁸}，K₁₄ = {1+c⁴u⁴+c⁸u⁸+c¹²u¹²}。脚本逐一核对：Ψ 在 K_d 上恒等于 Ψ(1)（d ≤ 10 全部情形 True）。
- 下界：Var_{G²} ≥ \|K_d\|φ(1)²/\|G²\|，\|G²\| = q^{d/2−1}，故 \|φ(1)\| ≫ q^{3d/4} ⟹ 放大。φ(1) = #{α ∈ F_{q^{2d}} : e₁ = ⋯ = e_{d−1} = 0} − q^{d+1}：(d+1) 维完全交 V_d = V(e₁,…,e_{d−1}) 的扭点数的次主项。d = 4：−q⁴+q³（权 2d）；d = 6：ε₀q⁵+q⁴−2q³（权 2(d−1)）；d = 8：−40, −6336, −491008 ≈ −1.9q⁶（阈值 q^{3d/4} = q⁶）。
